# SafeDrive AI Screenshots Guide

## Overview
This directory is the designated location for storing actual application screenshots for the college report, presentation, and GitHub README showcase.

**Important Directive**: Do NOT create, generate, or commit fake/fabricated screenshots. All screenshots must be captured from the actual deployed or local running application.

## Recommended Screenshots List

Capture and place the following images in this directory once the application is running and verified:

1. `01-login.png` - The authentication/login screen.
2. `02-dashboard.png` - The main user dashboard showing high-level stats.
3. `03-live-monitoring.png` - The active webcam monitoring view with the 3D facial mesh overlay.
4. `04-drowsiness-alert.png` - The UI state when a prolonged eye closure or yawn triggers a high-risk warning.
5. `05-distraction-alert.png` - The UI state when the phone detector or head pose logic triggers a distraction alert.
6. `06-history.png` - The trip history log.
7. `07-analysis.png` - The detailed analytics charts and telemetry graphs.
8. `08-notifications.png` - The system notification center.
9. `09-profile.png` - The driver profile and settings view.
10. `10-settings.png` - The system configuration page.

Once captured, you may link these images in the main project documentation.
