# SafeDrive AI — Feature Schema & Preprocessing Framework

This module defines the canonical feature schema, dataset adapters, subject-independent data splitters, and feature preprocessors for SafeDrive AI.

---

## Canonical Feature Schema (Version 1.0.0)

The model inputs are directly derived from the 10 real-time measurements generated by `TemporalFeatureEngine` and `FaceDetector`:

| Vector Index | Feature Name | Type | Physical Range | Typical Default | Source / Meaning |
| :---: | :--- | :---: | :---: | :---: | :--- |
| `0` | `current_ear` | `float32` | `[0.0, 1.0]` | `0.32` | Exponentially smoothed Eye Aspect Ratio (EAR). Lower values indicates closed eyes. |
| `1` | `mar` | `float32` | `[0.0, 2.0]` | `0.20` | Exponentially smoothed Mouth Aspect Ratio (MAR). Higher values indicates open mouth / yawning. |
| `2` | `eye_closed_duration_sec` | `float32` | `[0.0, 10.0+]` | `0.0` | Continuous duration in seconds that eyes have been closed below EAR threshold. |
| `3` | `perclos` | `float32` | `[0.0, 100.0]` | `0.0` | Percentage of eye closure frames over rolling 60-second window. |
| `4` | `blink_rate` | `float32` | `[0.0, 120.0]` | `15.0` | Number of detected valid blinks per minute in rolling 60-second window. |
| `5` | `yawn_duration_sec` | `float32` | `[0.0, 10.0+]` | `0.0` | Continuous duration in seconds of current active yawn. |
| `6` | `head_pitch` | `float32` | `[-90.0, +90.0]` | `0.0` | Head pitch angle in degrees (nodding up/down). |
| `7` | `head_yaw` | `float32` | `[-90.0, +90.0]` | `0.0` | Head yaw angle in degrees (turning left/right off-road). |
| `8` | `head_roll` | `float32` | `[-90.0, +90.0]` | `0.0` | Head roll angle in degrees (tilting side-to-side). |
| `9` | `phone_confidence` | `float32` | `[0.0, 1.0]` | `0.0` | Mobile device detection confidence score from object detector. |

---

## Data Leakage Prevention Rules

1. **Scaler Fitting**: `StandardScaler` parameter calculations (mean $\mu$, variance $\sigma^2$) are computed **strictly on the Training split**.
2. **Subject Splitting**: Partitioning is grouped strictly by `subject_id` using `GroupKFold`. No driver present in the Training split may ever appear in Validation or Test splits.
3. **Missing Value Imputation**: Forward-fill imputation is limited to consecutive missing face frames $< 500\text{ ms}$. If face loss exceeds $500\text{ ms}$, metrics reset to initial baseline values.
